Before you start

  • Windows 10 or 11 (64-bit). StellarFITS doesn't run on Mac or Linux yet.
  • About 250 MB of free disk space.
  • No administrator rights needed - StellarFITS installs just for you by default.
  • Nothing else to install first. StarNet2 and GraXpert are optional extras you can add later.

It takes about two minutes.

1. Download

On stellarfits.co.uk, click Download. Your browser saves StellarFITS-Setup.exe (about 52 MB) - usually in your Downloads folder.

Microsoft Edge will probably warn that the file "isn't commonly downloaded". That's because StellarFITS is new and few people have downloaded it yet - it doesn't mean anything is wrong with the file.

  1. In Edge's downloads list, click the message "StellarFITS-Setup.exe isn't commonly downloaded" (or point at it and click … then Keep).
  2. In the box that opens, click the small arrow next to Delete and choose Keep anyway.

Other browsers (Chrome, Firefox) may ask in their own way whether to keep the file - choose Keep.

2. Check the download (optional)

Next to the Download button there is a SHA-256 code - a fingerprint of the file. If you'd like to be sure your download is exactly the file we published:

  1. Open your Downloads folder, right-click an empty space and choose Open in Terminal.
  2. Type Get-FileHash StellarFITS-Setup.exe and press Enter. If it says "not recognized", the terminal is Command Prompt - type certutil -hashfile StellarFITS-Setup.exe SHA256 instead.
  3. The long code under Hash should be exactly the same as the one on the website.

3. Windows' "protected your PC" warning

Double-click StellarFITS-Setup.exe (in Edge you can click Open file in the downloads list). If you already chose Keep anyway in Edge, the installer usually just starts.

Otherwise - especially if you downloaded with another browser - Windows may show a blue box saying "Windows protected your PC". Because this beta isn't digitally signed yet, that's normal for a new program from a small developer:

  1. Click More info (under the text in the blue box).
  2. Check that it says StellarFITS-Setup.exe, then click Run anyway.

Your antivirus may scan the file first - that's fine. If it blocks it, please tell us (support@stellarfits.co.uk): new programs are sometimes flagged by mistake.

4. Install

Install for me only is recommended - no administrator password needed. (Install for all users puts it in Program Files for everyone on the PC and asks for administrator rights.)

Licence. StellarFITS is free to use, and the pictures you make with it are yours. Choose I accept the agreement, then Next.

Beta notes. What helps us most, and what isn't supported yet. Click Next.

Where to install. The suggested folder is fine - click Next.

Desktop icon. Tick Create a desktop shortcut if you'd like one, then Next and Install. Installing takes a few seconds.

Done. Leave Launch StellarFITS ticked and click Finish. StellarFITS is now in your Start menu, together with the StellarFITS User Guide.

5. First start

The first time StellarFITS starts, a welcome window shows two optional free programs by other authors that make your pictures better:

  • StarNet2 separates the stars from the nebula, for cleaner stars and a stronger nebula (recommended).
  • GraXpert removes light pollution and gradients, and adds AI noise reduction.

Download opens each program's own website. Install it, then press Check again - or click Continue without them and add them any time from Tools → StarNet2 and GraXpert.

Then open your first stacked FITS file with Open. The StellarFITS User Guide (in the Start menu, or Tools → User guide) takes you through it step by step.

Updating and removing

New version? StellarFITS tells you with a small New version link at the top right of its window. Download the new installer from the website and run it - it replaces the old version. Your settings and your own presets are kept.

To remove StellarFITS: Start menu → Uninstall StellarFITS, or Windows Settings → Apps → Installed apps → StellarFITS → Uninstall. Your settings and presets stay in %APPDATA%\StellarFITS in case you reinstall - delete that folder too if you want everything gone. StellarFITS never changes your FITS files or your pictures.
